## Content Rules

Content JSON may provide validated plain text, block structures, local media objects, canonical routes, and SEO metadata. Raw HTML, arbitrary fields, remote media, QR or barcode visuals, machine-readable code images, and local submission endpoints are forbidden.

## Minimal Examples

The machine contract contains a minimal example for every supported page type. Each minimal example includes shared brand and SEO fields plus required page data.

## Complete Examples

The machine contract contains a complete example for every supported page type, including optional home headings, featured media, card covers, and product FAQs.

## Validation

Run `npm run validate`, `npm run build -- --changed`, `npm run report`, the data-struct audit, static-site audit, and font audit. Never edit `dist` or `.ai-cms` reports directly.

## Unsupported Data

Rejected structures include remote or unlicensed image URLs, copied reference source, unlicensed fonts, raw HTML, QR or barcode images, unsupported JSON fields, local form submission, and third-party application state.

## Change Maintenance

When adding a field, update the Schema, builder ViewModel, field table, JSON block, examples, consumers, and image slots. When adding a token, update `tokens.json`, the theme-vars emitter, CSS consumer, settings table, and fallback.
