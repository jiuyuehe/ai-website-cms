# AI-Static-Website-Platform-PRD-v1.0

## 产品定位

AI-Static-Website-Platform 是一个基于 Headless CMS、Static Generator 和
AI Agent 的企业级静态网站生成平台。

目标：

通过结构化数据 + 模板 + AI生成规则，自动生成 SEO
友好的企业官网，并支持长期增量维护。

------------------------------------------------------------------------

## 核心架构

    Content 数据
        |
        v
    Template 模板
        |
        v
    Static Generator
        |
        v
    SEO 静态网站

------------------------------------------------------------------------

## 功能范围

### 内容管理

支持：

-   企业信息
-   联系方式
-   导航菜单
-   产品
-   案例
-   新闻
-   下载资料
-   FAQ

------------------------------------------------------------------------

### 数据与模板分离

要求：

-   内容不写入模板
-   模板不包含业务数据
-   AI 不直接修改生成HTML

------------------------------------------------------------------------

## 产品管理

产品数据：

    content/products/

支持：

-   产品介绍
-   核心功能
-   技术优势
-   应用场景
-   FAQ
-   文档下载
-   SEO信息

------------------------------------------------------------------------

## 静态生成器

流程：

    读取内容

    ↓

    Schema验证

    ↓

    模板渲染

    ↓

    生成HTML

    ↓

    生成SEO

    ↓

    输出dist

输出：

    dist/

    index.html

    products/

    cases/

    news/

    sitemap.xml

    robots.txt

------------------------------------------------------------------------

## CLI

支持：

    ai-cms build

全量生成。

    ai-cms build products

模块生成。

    ai-cms build --changed

增量生成。

    ai-cms validate

数据校验。

    ai-cms report

构建报告。

------------------------------------------------------------------------

## SEO要求

所有页面支持：

-   Title
-   Description
-   Keywords
-   Canonical
-   OpenGraph
-   Schema.org
-   Sitemap

------------------------------------------------------------------------

## 产品中心

要求：

-   产品列表动态生成
-   产品独立HTML
-   页面内部展示详情

禁止：

-   新标签页
-   window.open
-   target=\_blank
-   iframe

------------------------------------------------------------------------

## AI Agent维护流程

正确：

    修改content

    ↓

    validate

    ↓

    build

    ↓

    report

禁止直接修改dist。
